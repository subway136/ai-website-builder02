# Aura Intelligence - Next-Gen AI Automation Agency

A high-tech, futuristic SaaS landing page and platform for an AI automation agency. Built with Next.js 15, React 19, Framer Motion, and Tailwind CSS.

## Quick Start

bash
npm install
npm run dev


## Tech Stack

- **Next.js 15 (App Router)**
- **React 19**
- **Framer Motion** (Animations)
- **Tailwind CSS** (Styling)
- **Lucide React** (Icons)

## Features

- **Glassmorphism UI**
- **AI ROI Estimator Tool**
- **Interactive AI Chatbot UI**
- **Animated Process Roadmaps**
- **Responsive Case Studies**
- **Calendly Booking Ready**
